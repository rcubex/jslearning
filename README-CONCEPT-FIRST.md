# JS Learning — Concept-first Web/Application Academy

The 190 Application Academy lessons now begin with a technology-first textbook reader and visual conceptual workflow. Curated extra chapters expand cornerstone topics such as HTTP, cookies, TLS, web browsers, backend, API, identity, payments and mobile. Security and pentesting walk-throughs appear only after these concept sections, in a final expandable area.

## Deploy

Replace the site root `index.html`; all existing support assets remain unchanged. Use an incognito/private window or a hard refresh to verify. Progress keys and Firebase configuration are untouched.

## Notes

Text-only workflow diagrams are illustrative, not literal network traces. For testing use systems you own or are authorized to assess. Guided labs remain educational activities, not hosted vulnerable labs.
