# V11: Sonoma glass theme for the whole app

The whole signed-in app now uses the macOS Sonoma glass look. Content, progress and all features are unchanged, and the login page is untouched.

- **Background.** A soft Sonoma-style wallpaper gradient (peach, pink, violet, blue) stays fixed behind every page.
- **Sidebar.** A frosted-glass sidebar with the red, yellow and green window dots, blue icons, Apple's system font, and grey Finder-style highlighting for the current page.
- **Frosted glass everywhere.** Cards, panels, tables, lesson cards, quiz options, inputs and buttons, the CISA hub, the mock-exam screens and the Mistakes notebook all use see-through frosted glass.
- **Banners.** The dashboard, module, GRC and Application banners are dark smoked glass.
- **Light and dark.** The Theme button still switches between Light, Dark and Auto. Dark mode uses a deep, glowing version of the wallpaper.
- **Colour swatches removed.** The app always uses this theme.
- **Phones.** A frosted top bar and a ☰ menu.
- **Accessibility.** If "Reduce transparency" is turned on in your device settings, cards become solid.

## Deploy
Upload `index.html` and `service-worker.js` (and `cisa/` if it isn't already updated), then hard refresh once.
